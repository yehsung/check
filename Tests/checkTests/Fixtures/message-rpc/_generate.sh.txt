#
# 직렬화는 PostgREST 와 같게:
#   · 표 반환(message_history_with_reads · message_history · take_pokes) → select coalesce(json_agg(t), '[]'::json) from f(...) t
#   · jsonb 반환(message_unread_summary · mark_messages_read · send_message) → select f(...)::text (값 그대로)
#   파일 끝의 psql 줄바꿈 한 개만 걷는다(서버 출력 바이트 그대로 — json_agg 가 넣는 원소 사이 줄바꿈은 남는다).
#
# 단계마다 psql 세션 하나(= PostgREST 요청 하나): migrator → set role postgres → begin → (준비 SQL) →
#   harness.login(호출자) → RPC → commit | rollback. 읽음 경계를 올리는 호출은 commit, 나머지 들여다보기는 rollback.
#
# 사용: generate.sh [DEST]
#   DEST 가 있으면 완성된 픽스처를 그 폴더로 복사한다(예: <워크트리>/Tests/checkTests/Fixtures/message-rpc).
#   환경: HARNESS_PORT(기본 55521) · SKIP_INIT=1(이미 켜 둔 클러스터를 쓴다) · STOP_CLUSTER=1(끝나면 클러스터를 끈다)
# 운영에는 닿지 않는다 — lib.sh 가 PG* 를 지우고 127.0.0.1:$HARNESS_PORT 로 못 박는다.
# ══════════════════════════════════════════════════════════════════════════════════════════════
