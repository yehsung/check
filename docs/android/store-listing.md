# 스토어 등록정보 초안 (한국어)

- **초안이다.** 사용자가 읽고 고친 뒤 Play Console → 성장 → 스토어 등록정보 · 스토어 설정에 옮긴다.
- 정본은 옮긴 뒤의 콘솔이다(README).
- 글자 수 한도는 Play Console 입력칸 기준이다: 앱 이름 30 · 간단한 설명 80 · 자세한 설명 4000 · 출시 노트 500.
  - 일반 지식으로 적었다. 입력칸이 보여 주는 남은 글자 수로 다시 확인한다.
  - 검사기는 공백·줄바꿈까지 센다(보수적).
- 문구 바탕은 iOS 설명이다. iOS 설명은 2026-10-23 에 App Store Connect 에서 읽어 와 1.0.13 기준으로 맞춘 판이다(`docs/appstore.md` §1.4).
  - Android 에 맞게 바꾼 곳은 §3 아래 표에 적었다.

## 2. 간단한 설명 (80자)

<!-- field: short_description · 최대 80자 -->
```text
우리 팀이 지금 누가 일하는지 한눈에. 근무 기록, 1:1 메시지, 미니게임과 1:1 대결까지.
```

- 대안(같은 한도 안):
  - `팀 근무 현황을 한눈에. 근무 시작·종료, 1:1 메시지, 미니게임, 오목·체스·테트리스 대결.`
  - `팀 근무 현황 · 메시지 · 미니게임`(iOS 부제 그대로, 20자)
- 피한 것:
  - '판돈'·'루비 걸기'를 앞세우지 않는다. 모의 도박은 등급 설문에 사실대로 답하고([content-rating.md](content-rating.md)), 홍보 문구로 쓰지 않는다.
  - '1위'·'무료'·'최고' 같은 순위·가격 낱말과 이모지는 넣지 않는다(Play 메타데이터 정책의 흔한 반려 사유 — 일반 지식).

### 3.2 제출 직전 — 실제 빌드와 대조할 것

설명문(§2·§3·§4)과 영어 지시문(`app-access.md` §2)은 실제 빌드를 따라가야 한다.

- 두 칸의 문장마다 아래 표에 한 줄씩 있다. 문장을 더하면 이 표에도 줄을 더한다.
- 한 줄이라도 빌드와 다르면, 문장을 빼거나 고친 뒤 제출한다.
- '칸' 열: 설명 = §3 자세한 설명 · 간단 = §2 · 노트 = §4 출시 노트 · 지시문 = 영어 심사 지시문.

### 3.3 콘솔 칸 금지 문구 (검사기)

검사기는 콘솔에 옮길 여섯 칸(§1 · §2 · §3 · §4 와 `app-access.md` §2 의 두 지시문)에 같은 금지 목록을 건다. 한 칸에서라도 나오면 빨강이다. 영어 문구와 이유는 [app-access.md](app-access.md) §3 에 있다. 한국어 문구는 아래와 같다.

| 금지 문구 | 왜 |
|---|---|
| `길건너` · `역대` | 길건너 아잉이와 역대 순위 [오늘\|역대] 전환은 Android 첫 판에 넣지 않는다(G §8-18 #7) |
| `아이폰` · `앱스토어` · `테스트플라이트` | 다른 스토어의 플랫폼 이름이다. iOS 설명을 옮기다 남기 쉽다 |
| `맥에서만` · `맥 앱에서만` | 폰 근무 시작·종료는 iOS 1.0.7 부터 되고, Android 는 첫 판부터 된다 |
| `두 가지 미니게임` · `미니게임 둘` 꼴 | 미니게임은 셋이다 |
| `도전 미션` | iOS 1.0.13 에서 「누적 미션」으로 바뀐 옛 이름이다(§3.1 #2) |
| `수수료` | 대결 수수료는 2026-10-22 에 없어졌다 |

- 칸 밖(이 문서의 표·메모)은 금지 목록을 재지 않는다. 바꾼 곳을 설명하려면 옛 문구를 적어야 하기 때문이다.
- 꼭 있어야 할 문구도 잰다. §3 자세한 설명에는 웹 삭제 주소, "현금으로 사거나 바꿀 수 없", "다른 사람에게 보낼 수도 없", "확률은 앱 안에 공개" 가 있어야 한다(E §9.1 (a)(c) · §9.4 · §9.6).

| 자산 | 규격(일반 지식 — 콘솔 업로드 칸에서 재확인) | 계획 |

  - Android 데모 모드는 E §4.6 의 `stub` 소스셋이다. 릴리스 APK 에는 픽스처가 없어야 한다.
- **[확률 보기] 시트와 상점 가격표는 찍지 않는다.** 스토어 이미지에 확률·가격 숫자가 박히면 서버가 바꾸는 날 거짓이 된다(README 규칙).

  - 상금 숫자가 안 보이는 구도를 고르는 쪽을 추천한다.
