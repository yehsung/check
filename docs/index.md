# 아잉체크

**아잉체크**(aing-check)는 일하는 시간을 스스로 재고, 팀이 지금 어디쯤인지 한눈에 보는 앱입니다.
맥 메뉴바 앱과 아이폰 앱이 같은 계정으로 이어집니다.

## 무엇을 하나요

- **근무 타이머** — 시작과 종료는 맥 메뉴바에서. 오늘 얼마나 일했는지, 이번 주 목표까지 얼마나 남았는지 보여 줍니다.
- **팀 현황** — 지금 누가 일하고 있는지, 이번 주 팀 순위는 어떤지.
- **메시지 · 할 일** — 팀원과 1:1 메시지, 오늘 할 일 체크. 아이폰 홈 위젯에서도 보입니다.
- **캐릭터와 루비** — 일한 만큼 루비를 모아 캐릭터를 얻습니다. 미니게임과 1:1 오목도 있습니다.

## 지원

- **앱 안에서 바로 문의** — 아이폰: 나 → 제보 / 맥: 설정 → 제보. 보낸 글에는 답장이 옵니다.
- **버그 신고 · 기능 요청** — [GitHub Issues](https://github.com/yehsung/check/issues)

## 불쾌한 메시지를 받았다면

- **신고** — 아이폰 앱의 대화 화면 오른쪽 위 **···** → [신고하기]. 받은 메시지를 **길게 눌러** 그 메시지만 신고할 수도 있습니다.
  오목 대국 중에는 아래 대화 서랍 오른쪽 위 **···** 에 같은 [신고하기]가 있습니다.
  신고 내용은 운영자만 봅니다. **접수한 신고는 24시간 안에 확인합니다.**
- **차단** — 같은 **···** 메뉴의 [차단하기](대화 화면·오목 대화 서랍 둘 다). 차단하면 서로 메시지를 주고받을 수 없고,
  사람 찾기·오목 신청에서도 서로 보이지 않습니다. **나 → 설정 → 차단한 사람**에서 언제든 풀 수 있습니다.
- 앱을 쓸 수 없는 상황이면 [GitHub Issues](https://github.com/yehsung/check/issues) 로도 신고를 받습니다.

## 계정 삭제

아이폰 앱에서 **나 → 설정 → 계정 삭제** 로 직접 지울 수 있습니다.
지우면 근무 기록·메시지·할 일·캐릭터·루비·순위 기록이 서버에서 함께 사라지며 되돌릴 수 없습니다.
