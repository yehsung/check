# '없음 칸' 계약 — 코덱스 5시간 창이 없는 계정의 화면 (2026-10-30 사용자 승인)

## 왜 고치는가 (사실)

코덱스는 **요금제에 따라 창을 하나만 보낸다.** `plus` 는 둘(primary 300분 + secondary 10080분),
**`pro`·`prolite`·`free` 는 주간 하나뿐이고 그 하나가 `primary_window` 라는 이름으로 온다.** 운영 코덱스
사용자 40명 중 **38명(≈95%)** 이 그 요금제라, 그들의 5시간 칸은 영구히 `없음` 이다.

앱은 이미 그걸 **맞게** 그린다(`없음` + 더 어두운 트랙). 결함은 셋이다.

1. **왜 없는지를 말하지 않는다.** 맥 툴팁은 `5시간 없음` 한 마디뿐이다.
2. **그 `없음` 이 안 읽힌다.** 다크 대비 **2.06:1**(숫자는 12.32:1) — 어떤 글자에도 모자란 값이고,
   없는 칸 트랙은 0% 바와 모양이 같다.
3. **먼 리셋 시각에 날짜가 없다.** 11월 4일 리셋을 `오후 4:14` 로 적어 **5일 뒤를 오늘 오후로** 말한다.
   주간 창은 항상 이 갈래라 전원이 본다.

사용자 결정(2026-10-30): **넷 다 고친다 — 맥·폰 같이.** 이 문서가 세 화면이 공유하는 값의 정본이다.

## 구조 제약 (이 계약이 필요한 까닭)

맥 앱 타깃은 `CheckMobileShared` 를 **링크하지 않는다**(셋이 공통으로 보는 모듈은 `CheckCore` 뿐).
그래서 승인본 16진수를 **맥과 공용 모듈에 따로 적고**, 갈리지 않는지는 소스 계약 시험이 되묻는다:
`Tests/CheckMobileKitTests/MeAILimitsTests.swift` 의 `columnPaletteIsOneTableAcrossSurfaces` 가
`AILimitColumnPalette.*.dark` 의 16진수를 **맥 소스에서 grep 한다.** 한쪽만 고치면 그 자리에서 빨개진다.

## ① 글자 — 바꾸지 않는다

`없음` 그대로. `—` 는 쓰지 않는다(코어가 '판정 불가 = 못 읽었다'로 못 박은 글자다).
`AILimitColumnText.absentValueText` ↔ `AILimitCardModel.absentValueText` 소스 계약 유지.

## ② 색 — 승인된 3단 글자 토큰의 값으로 올린다

새 회색을 발명하지 않는다. **`MobileThemePalette.label3Text`**(주석: "3단 **글자** … 카드·바탕 위 4.5:1")를
각 바탕에 합성한 값을 쓴다 — 이미 승인된 위계의 '읽히는 가장 조용한 글자'가 정확히 이 자리다.

| | 지금 | 새 값 |
|---|---|---|
| `absentText` light | `#9BA1AC` (흰 바탕 2.60:1) | **`#717176`** (4.85:1) |
| `absentText` dark | `#595E67` (카드 2.06:1) | **`#9798A4`** (카드 4.70 · 위젯 5.26 · 맥 5.24:1) |

- 고칠 자리 둘: `Sources/CheckMobileShared/AILimitColumnStyle.swift` 의 `absentText`,
  `Sources/check/CheckAILimitsRow.swift` 의 `AILimitMacPalette.absentText`(= dark 값 `0x97_98_A4`).
- `absentTrack`(light `#F1F2F5` · dark `#22262C`)과 `emptyTrack` 은 **그대로 둔다** — 그 둘의 밝기 차를
  재는 시험이 셋 있고, 어두움이 "0% 라 비었다"와 가르는 단서다.

### 시험의 상한을 절대값에서 **상대값**으로 바꾼다

`MeAILimitsTests.swift:493-494` 가 지금 `ratio < 4.5` 로 **읽히는 것을 금지**한다. 그 단언의 본래 뜻은
"값이 아니라 '값이 없다는 사실'이라 숫자보다 조용해야 한다"이고, 그 뜻은 **상대 비교로 지켜야** 한다:

```
#expect(ratio >= 4.5)                       // 읽힌다(새 하한)
#expect(ratio < 숫자_글자의_대비)            // 숫자보다는 조용하다(원래 뜻 유지)
```

숫자 글자 기준선: light `#0B0B10` on 흰 = 19.63:1 · dark `#F4F5F5`(= `label` 흰 0.95 합성) on 카드 = 12.32:1.

## ③ 색이 아닌 단서 — 없는 칸 트랙에 사선 해치

틴트 모드·색맹·흑백에서도 0% 바와 갈리게. **세 화면이 같은 수를 쓴다**(맥은 따로 적는다):

| 매개변수 | 값 |
|---|---|
| 각도 | 45° (왼쪽 아래 → 오른쪽 위) |
| 선 굵기 | `1` pt |
| 선 간격 | `4` pt |
| 선 색 | `absentText` 의 **45% 불투명도** |
| 그리는 범위 | 트랙 캡슐 안쪽으로 클립 |

- 구현은 `Canvas { ctx, size in … }` — `size` 를 받으므로 `GeometryReader` 가 필요 없고 위젯 단일 렌더에서도
  안전하다. 값이 **있는** 칸(0% 포함)에는 **절대 그리지 않는다**.
- 상수 이름을 세 화면에서 같게: `absentHatchSpacing = 4` · `absentHatchLineWidth = 1` ·
  `absentHatchOpacity = 0.45`. 소스 계약 시험이 맥 소스에서 이 세 수를 grep 한다.

## ④ 이유는 **칸이 아니라 한 번만** 말한다

칸 폭이 52pt(`AILimitRowWidthBudget.valueWidth`, 최악 50.96pt)라 `없음` 말고 더 들어갈 자리가 없다.
그리고 칸마다 이유를 세우면 38명이 줄마다 같은 문장을 읽는다.

- **맥 — 툴팁의 없는 칸 줄에 붙인다.** `Sources/check/CheckAILimitsRow.swift` 의 `tooltipText`:
  ```
  Codex prolite
  5시간 없음 — 지금 요금제는 주간 한도만 알려 줘요
  주간 5% · 2분 전 · 11/4 오후 4:14 리셋
  ```
  ★ **이유는 있는 창에서 끌어낸다**(커밋 전 리뷰에서 고침): `absentReasonText(present:)` =
  `"지금 요금제는 \(남은 창 이름) 한도만 알려 줘요"`. 5시간이 빈 줄(38명)에는 위 승인본 글자 그대로 나가고,
  **주간이 빈** 줄에는 `주간 없음 — 지금 요금제는 5시간 한도만 알려 줘요` 가 된다. 처음 계약처럼 상수로 박으면
  주간이 빈 줄에서 "주간 없음 — 지금 요금제는 주간 한도만 알려 줘요" 라는 **자기모순**이 나가고, 그런 계정이
  운영에 실제로 있다(코덱스 크레딧 사용자 — 5시간 값·주간 null 인 살아 있는 행).
- **폰 — 카드 캡션에 한 줄 더한다.** `Sources/CheckMobileKit/Me/MeAILimitsText.swift` 의 `aiLimitsCaption`:
  `"5시간 창과 주간 창에서 쓴 비율이에요. 요금제에 따라 창이 하나만 올 수 있어요."`
  (지금 문장은 35명 중 30명에게 거짓이다.)
- **보이스오버는 그대로** `5시간 없음`(`aiLimitAbsentAccessibility`). 캡션이 이미 읽히므로 소리에서 이유를
  반복하지 않는다.
- ★ **진단 어휘 금지**: `primary_window`·창 길이·`plan_type`·파서·초 같은 말은 사용자 툴팁의 것이 아니다
  (2026-09-22 결정 · `AILimits.swift:149-152` 규약). '요금제'는 사용자 어휘다.

## ⑤ 맥 리셋 글자 — 하루를 넘으면 날짜를 적는다

`AILimitResetTimeText`(맥 전용 — 폰·위젯은 리셋 **시각**을 그리지 않고 나이만 말한다):

- 리셋이 **24시간 안쪽**이면 지금처럼 `오후 4:14`.
- **24시간을 넘으면** `11/4 오후 4:14` (`M/d a h:mm`).
- 기준 시각이 필요하므로 시그니처에 `now:` 를 더한다. **기본값을 주지 마라** — 호출부가 명시하게 해서
  "지금을 안 넘긴 자리"가 컴파일에서 드러나게 한다.
- 기존 시험 `resetTimeCaptionHasNoSeconds`(`Tests/checkTests/AILimitsMacTests.swift:2051`)의
  `hasPrefix("오전"|"오후")` 단언은 **같은 날 리셋으로 고정해 유지**하고, 먼 리셋이 날짜를 담는 단언을
  **새로 더한다**. 초를 쓰지 않는다는 원래 계약은 양쪽에서 그대로다.

## ⑥ 그물 — 새로 박을 단언

지금 스위트는 "`없음` 이 뜬다"까지만 지키고 **"왜인지"와 "먼 리셋의 날짜"는 한 건도 재지 않는다.**

1. 맥: `prolite` + 주간 전용 코덱스 줄의 **툴팁이 이유 문구를 담는다**.
2. 맥: 24시간 넘는 리셋 글자가 **날짜를 담고**, 24시간 안쪽 글자는 **담지 않는다**.
3. 폰: `absentText` 대비가 **4.5:1 이상이고 숫자보다 작다**(위 상대 상한).
4. 폰: 캡션이 **요금제 한 줄을 담는다**.
5. 셋: 사선 해치의 세 수가 **맥 소스에도 그대로** 있다(소스 계약 grep).

★ 단언은 **부르는 자리**를 재라. "상수가 있다"는 "화면이 그렇게 된다"의 증거가 아니다.

## 건드리지 않는 것

- **파서·규칙·스토어·서버**: 숫자 경로는 이미 옳다. 5시간 칸이 빈 것은 제공자가 안 보내기 때문이다.
  `AILimitReaders.swift` 의 길이 기반 분류(10-23 수리)는 **그대로 둔다.**
- **운영 DB**: 잘못 앉은 5행은 그 맥이 0.3.65+ 로 올라가면 업로더의 명시적 null 이 자동 교정한다.
  5시간 칸만 지우면 창이 0개가 되어 `hasAnyWindow` 에 걸려 **코덱스 줄이 통째로 사라진다** — 더 나쁘다.
- `absentValueText`(`없음`)·`absentTrack`·`emptyTrack` 의 값.
