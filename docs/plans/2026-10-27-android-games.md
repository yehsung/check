# 구현·검증 순서

1. JVM 테스트: 난수·타이밍 점수 경계·10라운드 종료·플래피 중력/충돌·상한·판 토큰 생명주기를 먼저 정의한다.
2. 순수 Kotlin 엔진과 판 게이트를 구현하고 원본 Swift 궤적과 대조한다.
3. MockWebServer로 인증·갱신·RPC 인자·비공개 거부·한 토큰 한 제출을 검증한다.
4. Compose로 게임 목록·로그인·연습·순위 모드·일일 순위를 연결한다.
5. APK 빌드·lint·테스트를 실행하고 가능하면 Android 에뮬레이터에서 실행·화면을 검증한다.
6. 설치 방법·기능 범위·실서버 확인 한계를 README와 PR에 기록한다.
