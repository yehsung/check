# 개인정보 원칙

`aing-check`는 근무 시작/종료 기록과 팀 상태 표시만 다룹니다.

## 수집하는 데이터

- 이메일
- 표시 이름
- 팀 멤버십
- 근무 시작/종료 시각
- 현재 근무 상태
- 프로필 아바타 이미지(선택 — 팀원이 직접 고른 경우에만 공개 아바타 버킷에 저장)
- 기기 식별자(앱이 이 Mac에서 처음 실행될 때 만든 무작위 UUID. 같은 계정으로 여러 Mac을 쓸 때 AI 도구 사용량을 덮어쓰지 않고 합산하기 위한 용도이며, 기기 이름·모델·일련번호 같은 정보는 담지 않습니다)

로그인 비밀번호는 Supabase Auth 요청에만 사용하며 앱 저장소에 저장하지 않습니다. 다음 실행 때 편하게 이어 쓰도록 이메일, 별명, 그리고 로그인 세션 정보(액세스/리프레시 토큰과 사용자 식별자 UUID)는 이 Mac의 사용자 기본값(UserDefaults)에 저장됩니다. 세션이 만료되어 재로그인이 필요해지면 저장된 세션 정보는 지워집니다.

## 수집하지 않는 데이터

- 스크린샷
- 키보드 입력
- 마우스 움직임
- 앱/웹사이트 사용 기록
- 카메라, 마이크, 위치 정보
- 생산성 점수

## 자동 근무 시작(넛지) 기능

쉬는 중에 컴퓨터를 한동안 쓰고 있으면 앱이 근무를 자동으로 시작합니다. 이 기능은 시스템이 알려 주는 **"마지막 입력 후 경과 시간"** 숫자 하나만 확인하며(운영체제가 권한 없이 제공하는 값), 무엇을 입력했는지·화면에 무엇이 있는지는 전혀 접근하지 않습니다. 이 숫자는 로컬에서만 쓰이고 서버로 보내지 않습니다.

자동 시작은 몰래 일어나지 않으며, 다음 세 가지로 확인하고 되돌릴 수 있습니다.

- 시작하는 순간 캐릭터가 말풍선으로 알려 줍니다(캐릭터를 숨겨 둔 경우에는 메뉴바 아이콘이 근무중으로 바뀝니다).
- 시작 후 60초 안에는 메뉴바 팝오버에서 **[취소]** 를 눌러 방금 시작한 근무를 없던 일로 만들 수 있습니다.
- 내 근무 상자의 진행률 줄 오른쪽 **⚡ 자동 근무 시작** 토글을 끄면 이 기능이 완전히 멈춥니다(캐릭터 표시와는 별개 설정입니다).

## 개인 기록(근무 리듬·주간 회고)

요일별·시간대별 근무 리듬과 지난주 회고는 이미 저장된 내 근무 시작/종료 기록만으로 내 Mac에서 계산해 보여 주는 화면입니다. 이를 위해 새로 수집하거나 서버에 저장하는 데이터는 없으며, 다른 팀원에게 보이지도 않습니다.

## 요청하지 않는 권한

앱은 Accessibility, Screen Recording, Camera, Microphone, Location 권한을 요청하지 않아야 합니다.
