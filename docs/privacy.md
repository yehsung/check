# 개인정보 원칙

`aing-check`는 근무 시작/종료 기록과 팀 상태 표시만 다룹니다.

## 수집하는 데이터

- 이메일
- 표시 이름
- 팀 멤버십
- 근무 시작/종료 시각
- 현재 근무 상태
- 마지막으로 컴퓨터를 만진 시각(키·클릭·스크롤 중 가장 최근 것의 **시각 하나**. 무엇을 입력했는지는 담기지 않으며, 마우스 움직임만으로는 갱신되지 않습니다. 켜 둔 채 자리를 비운 근무를 자동으로 마감하는 데 씁니다 — 아래 "자리 비움 자동 근무종료" 참고)
- 프로필 아바타 이미지(선택 — 팀원이 직접 고른 경우에만 공개 아바타 버킷에 저장)
- 기기 식별자(앱이 이 Mac에서 처음 실행될 때 만든 무작위 UUID. 같은 계정으로 여러 Mac을 쓸 때 AI 도구 사용량을 덮어쓰지 않고 합산하기 위한 용도이며, 기기 이름·모델·일련번호 같은 정보는 담지 않습니다)

로그인 비밀번호는 Supabase Auth 요청에만 사용하며 앱 저장소에 저장하지 않습니다. 다음 실행 때 편하게 이어 쓰도록 이메일, 별명, 그리고 로그인 세션 정보(액세스/리프레시 토큰과 사용자 식별자 UUID)는 이 Mac의 사용자 기본값(UserDefaults)에 저장됩니다. 세션이 만료되어 재로그인이 필요해지면 저장된 세션 정보는 지워집니다.

## 수집하지 않는 데이터

- 스크린샷
- 키보드 입력
- 마우스 움직임
- 앱/웹사이트 사용 기록
- 카메라, 마이크, 위치 정보
- 생산성 점수

## 자동 근무 시작(넛지) 기능

쉬는 중에 컴퓨터를 한동안 쓰고 있으면 앱이 근무를 자동으로 시작합니다. 이 기능은 시스템이 알려 주는 **"마지막 입력 후 경과 시간"** 숫자 하나만 확인하며(운영체제가 권한 없이 제공하는 값), 무엇을 입력했는지·화면에 무엇이 있는지는 전혀 접근하지 않습니다. 이 기능이 보는 숫자 자체는 로컬에서만 쓰입니다. 다만 **근무 중**에는 그 숫자에서 계산한 "마지막으로 만진 시각" 하나를 서버로 보냅니다(아래 문단).

자동 시작은 몰래 일어나지 않습니다. 시작하는 순간 캐릭터가 말풍선으로 알려 주며(캐릭터를 숨겨 둔 경우에는 메뉴바 아이콘이 근무중으로 바뀝니다), 원치 않으면 메뉴바 팝오버에서 **근무 종료** 를 누르면 됩니다.

## 자리 비움 자동 근무종료

근무를 켜 둔 채 잠들거나 잊고 자리를 뜨는 일이 있어서, 오래 아무것도 만지지 않으면 앱이 근무를 자동으로 마감합니다. 마감 시각은 **마지막으로 만진 시각**이며, 자리를 비운 뒤의 시간은 근무로 세지 않습니다.

이 판단에 쓰는 것은 **시각 하나뿐**입니다.

- 보내는 것: "마지막으로 키·클릭·스크롤을 한 시각". 30초에 한 번까지만 갱신됩니다.
- 보내지 않는 것: 무엇을 입력했는지, 어떤 앱·사이트를 썼는지, 화면에 무엇이 있었는지. 마우스를 움직이기만 한 것은 "만졌다"로 세지 않습니다.
- 화면을 잠그면 그 시각은 더 이상 갱신되지 않습니다. 잠금 화면에서 비밀번호를 입력해도 근무가 연장되지 않습니다.

**잘못 마감됐다면 되돌릴 수 있습니다.** 회의·외출처럼 실제로 일하던 중이었다면, 돌아와서 되돌리기를 한 번 누르면 비운 시간까지 근무로 복구됩니다.

팀원에게는 자동 마감과 직접 누른 근무종료가 **구분되어 보이지 않습니다.** 누가 언제 자리를 비웠는지는 팀 화면에 나타나지 않습니다.

## 개인 기록(근무 리듬·주간 회고)

요일별·시간대별 근무 리듬과 지난주 회고는 이미 저장된 내 근무 시작/종료 기록만으로 내 Mac에서 계산해 보여 주는 화면입니다. 이를 위해 새로 수집하거나 서버에 저장하는 데이터는 없으며, 다른 팀원에게 보이지도 않습니다.

## 요청하지 않는 권한

앱은 Accessibility, Screen Recording, Camera, Microphone, Location 권한을 요청하지 않아야 합니다.
