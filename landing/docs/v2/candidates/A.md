### 0.2 사용자 요구 셋을 어디서 어떻게

1. **체험 제거** — 클릭하면 바뀌는 것이 0개다. 움직임은 시간(히어로 루프·엔드카드)·스크롤 위치(패럴랙스·트립틱)·문턱 1회(행 조립)로만 일어나고, 누를 수 있는 것은 내비·다운로드·App Store·brew 복사·FAQ `<details>`·푸터뿐(§3 각 절 '금지').
2. **다크 + 보라** — 밤은 무채에 가깝게 두고 보라는 **빛**으로만: 히어로 돔 림(레퍼런스 림 단면을 픽셀 단위로 옮긴 그라디언트, §2.2), 트립틱 오브젝트 뒤 글로우와 **보라 AI 토큰 잔디**, 행마다 그려지는 보라 연결선·점등 노드·보라 타일, FAQ 열린 행의 빛 헤어라인, 엔드카드 아잉 바닥 빛.
3. **레퍼런스 안무** — 장면 순서(히어로 돔 → 큰 숫자 3장 + `[ 01 / 03 ]` → 눈썹 칩 + 가운데 H2 → 10% 스파인 + 노드 행 조립 → 4×2 숫자 격자 → 검정 엔드카드)와 **타이밍 수치**(루프 4.2초·교체 267+333ms·점등 0.9~1.3초·행 조립 1.2~1.3초·점 격자 330ms·선 탁해짐 400ms·엔드카드 루프 2회)를 RA §4 그대로 옮겼다. 트립틱만 brief §5.1 대로 **가로**로 움직이고, 레퍼런스의 서명인 "가운데 고정 오브젝트 교체"는 지켰다(§3.3).

## 1. 컨셉과 원칙

### 1.1 한 문단
아잉체크는 화면 맨 위 메뉴바에 사는 앱이고, 레퍼런스는 행성의 지평선 위에서 돈이 오간다. 이 안은 그 행성을 **메뉴바 너머의 밤하늘**로 바꾼다. 첫 화면에는 보라 림이 빛나는 거대한 돔이 아래에서 솟아 있고, 돔 안쪽 아래에서 진짜 팝오버(근무중 03:45 · 5명 근무중)가 지평선 위로 떠오른다. 돔 안의 점 격자에서 혜성이 하나 출발해 림을 따라 호를 그리고, 꼬리 끝에서 앱 말풍선이 핀다 — "민트별님이 콕 찔렀어요!", 4.2초 뒤 "구름빵님: 커피 한잔 해요 ☕️", 다시 4.2초 뒤 "루비 +3!". 스크롤하면 돔은 천천히 가라앉고, 화면이 멈춘 채 큰 숫자 세 장(00:00 · 콕. · 12주)이 옆으로 흘러가며 가운데 오브젝트가 꺼진 채 들어와 보라로 켜진다. 그다음은 레퍼런스처럼 왼쪽 10% 선이 스파인이 되어 다섯 기능 행을 꿰고, 행마다 보라 선이 그려지며 렌더가 한 번 조립된다. 제품 사실 여덟 개의 숫자 격자, 설치, 질문을 지나면 화면이 검게 가라앉고 아잉이 폴짝 뛰며 "오늘도 화이팅!" 한다.

### 1.3 절제 원칙(구현자가 매번 확인)
1. 한 화면에 큰 것 하나, 글로우 하나(돔 / 오브젝트 뒤 / 행 타일 / 아잉 바닥). 그 밖의 보라는 1~1.5px 선과 작은 점뿐.
2. 바탕은 무채에 가까운 밤. 평평한 보라 면은 48px 타일 하나가 최대다(레퍼런스도 그렇다, RA §6.1-12).
3. 렌더는 크롭·축소·페이드 마스크만. 필터·덧그리기·커서 합성 금지 — 연출은 렌더 **밖**(선·림·글로우·그림자)에서.
4. 움직임은 §0.1 의 다섯 개뿐. 섹션 페이드업·카드 호버 들림·패럴랙스 추가 금지.
5. 불투명도는 언제나 선형. 이동·크기는 등장 ease-out / 퇴장 ease-in. 오버슈트는 말풍선·타일 '팝'에만.
6. 클릭하면 바뀌는 렌더 0. 허용 인터랙션은 brief §5.1 목록뿐.
7. 숫자는 렌더 속 또는 제품 사실만, 숫자마다 출처(§3.6). 한 뷰포트에 어긋나는 가상 수치 금지(v1 §1.3-8).
8. 한글이 주인공: 영문 소문자 라벨·대문자 눈썹 없음, 눈썹 칩은 페이지에 하나.

### 5.4 LCP · CLS · 스크롤
- LCP: desk = **H1 텍스트**(SSR + 500 서브셋 preload + swap). phone = **팝오버 렌더**(보이는 면적 331×240 > H1 300×92) → `fetchpriority="high"`. 목표 모바일 LCP ≤ 2.5s(4G).
- CLS ≤ 0.05: 모든 렌더 width/height 명시, 플랫폼 CTA 는 `PLATFORM_SCRIPT` 로 첫 페인트 전 결정, 트립틱 섹션 높이는 SSR 에서 `220svh`(세로판으로 갈 때는 `MQ_SCRUB` 미디어쿼리 CSS 로, JS 전에 결정).
- 스크롤 중 장기 작업 0: scroll 리스너 1개(passive) → rAF 1회에 `--hero-p`·`--tx` 두 변수만 쓰기. 변형은 transform·opacity 만(돔·트랙에 보일 때만 `will-change: transform`). 행 조립은 CSS 전이(`data-on` 한 번 붙이기).
- 캔버스 셰이더·3D 라이브러리·영상 배경 없음. 글로우는 전부 CSS 그라디언트.
