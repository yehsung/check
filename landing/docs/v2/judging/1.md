**1위 B.** 사용자가 "지저분해"라고 한 첫 화면을 가장 확실하게 지운다(돔 하나 + 아잉 하나 + 말풍선 하나). 보라를 앱 아이콘 링에서 표본해(#7E5EFA) "우리 가족의 보라"로 만든 유일한 안이고, 라벤더 아잉 몸이 화면 가운데 큰 라벤더 덩어리가 되어 "다크와 보라의 조화"를 그림 하나로 해결한다. 트립틱을 레퍼런스가 실제로 움직이는 방식(세로 스크롤 + 가운데 오브젝트 고정 교체)으로 옮긴 것도 B 뿐이다. 약점은 반복이다. 아잉이 여덟 번 나오고, 기능 행 여섯 개가 같은 구도를 쓴다. 자동 루프에 끝이 없는 것도 고쳐야 한다(§3.2 mustFix).

체험이 남은 안은 없다. 셋 다 fit 상한(10)에 걸리지 않는다.

**지저분함이 다시 생길 자리**: 히어로(혜성·펄스·말풍선·점 격자·잘린 팝오버), 행 R2(캐릭터 패널 + 루비 말풍선 + 할 일 보드 + 가지 셋), 행 R5(폰 + 위젯 둘 + 선 넷 + 앱 아이콘 타일).

**mustFix(A 가 1위가 되면)**
1. 히어로를 "큰 것 하나"로: 점 격자·펄스를 빼고, 말풍선 슬롯은 하나로, 팝오버는 접힘선 위에 다 들어오거나 아예 빼서 돔 + 글 + 말풍선 하나로.
2. 바탕 `--bg-0` 을 brief 의 보랏빛 밤(#0C0A14 근처)으로 되돌리고, 화면별 보라 하한을 수용 테스트로 건다(C 의 측정법).
3. 트립틱을 세로 + 오브젝트 sticky(레퍼런스 원형, A 의 감속 폴백을 기본으로 승격)로. 가로 마스크 연출 삭제.
4. 히어로 말풍선은 "알림 카드"가 아니라는 것이 읽히게(메뉴바 라벨이나 아잉 곁에 붙이기). 행 R2 의 `todo-board` 렌더는 빼거나 폰 위젯으로 대체.
5. iOS 'Mac 링크 보내기'(공유)를 허용 목록에 넣을지 리드가 결정하거나 App Store 링크로.

**graft(다른 안으로 옮길 것)**: 타일 안에 범용 아이콘 대신 **앱의 실제 메뉴바 아이콘(빨간 점 판)·앱 아이콘 렌더**를 넣는 것 · 행마다 구도를 다르게 하는 변주표(타일 유무·자식 수) · 아웃트로 commute-start → idle(앱에 있는 순서) · 루프 횟수 상한 · 메시지 행 "1이 사라짐" 한 번 교체 · 숫자 격자 칸마다 출처 줄.

**mustFix(종합 때 반드시)**

2. 아잉 노출을 5자리 이하로: B 의 축소 A(행 ①③④ 스틸 삭제, 말풍선만 렌더 옆)를 기본으로. 행에서 3D 캐릭터는 빼고 앱 렌더가 주인공.
3. 행 구도 변주: "행마다 다른 레이아웃 금지"를 지우고 A 의 변주(타일 유무·자식 수·카드 둘 배치)를 들인다. 행 ①②가 팝오버를 연달아 쓰지 않게(① 은 메뉴바 라벨 00:00 + 헤더 카드처럼 다른 물체로).
4. 첫 화면에 제품 사실 하나: 히어로 말풍선 아래나 메타 줄 옆에 실제 메뉴바 라벨(`menubar-0000`/`0345` 투명판, 1.5–2×)을 하나 — "메뉴바 앱"이 그림으로도 3초 안에 보이게. 아잉은 그대로 단 하나의 큰 것.
5. 아웃트로 반응을 앱에 있는 순서로: commute-end → idle 대신 ⓐ commute-start → idle(A) 또는 ⓑ idle 만. 「메뉴바에, 아잉 하나.」 헤드라인과도 ⓑ 가 맞는다.
6. iOS 'Mac 링크 보내기'(공유 시트)는 허용 목록 밖 — App Store 링크로(C 처럼) 또는 리드가 명시 허용.
7. 트립틱 방향(brief 는 가로, B 는 세로): 리드가 세로를 확정 기록(DECISIONS). 이 심사는 세로를 지지한다 — 사용자가 "영상 전체를 읽고 참고해"라고 했고 영상이 세로다.

**graft(다른 안으로 옮길 것)**: 앱 아이콘 링 표본 보라(#7E5EFA)와 그 근거 · 세로 sticky 트립틱 + 활성 띠 IO + 한 장 앞만 미리 받기 · `stage-bus`(동시 재생 1) · 반응 클립 공용 rest 포스터(바이트 동일) · 도착 마감 2.5초 · 1440×789(맥북 에어 실제 뷰포트) 시안 검증 · 설치 띠 윗변의 "돔 림을 편 수평선".

## 4. 종합에 바라는 모양(심사 1 의 제안)

뼈대 = **B**. 위에 얹을 것:
- B 의 돔 + 아잉 히어로는 그대로, 단 메뉴바 라벨 하나를 더해 첫 3초에 "메뉴바 앱"이 그림으로도 보이게(mustFix 4).
- B 의 세로 sticky 트립틱에 **C 의 지시선**을 입힌다: 「01:00」 → 렌더 칩 속 01:00. 숫자 무게는 C 의 300(또는 B 의 500) 중 실측으로.
- 행은 **A 의 변주 + A 의 실제 아이콘 타일**, 아잉 스틸은 빼고 렌더가 주인공(mustFix 2·3). 메시지 행 "1 사라짐"에 C 의 끝점 페이드.
- 보라는 B 의 아이콘 링 가족색, 검증은 **C 의 보라 면적 예산**(행 구간 하한 ≥ 1%).
- 루프 상한(A·C), 아웃트로는 앱에 있는 순서(A 또는 idle 만), 공유 시트 제거(C).

## 5. 리드가 정할 것

1. 트립틱 방향: brief §5.1 "가로" ↔ 레퍼런스 실측 "세로"(RA §0.2-2). 심사 1 은 **세로**.
2. iOS 'Mac 링크 보내기' 공유 버튼을 허용 목록에 넣을지.
3. WCAG 2.2.2 를 횟수 상한으로 갈음할지, "움직임 멈춤" 텍스트 버튼을 허용할지(A·C 가 같은 질문).
4. 아웃트로: brief §5.2 의 "commute-end → idle" 제안과 사실 규칙(퇴근 뒤 idle 은 앱에 없음) 중 어느 쪽.
