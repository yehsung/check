## 3. 후보 A — 85점

### 3.1 근거
- **fit 36**: 체험 0. 보라를 돔 림(레퍼런스 x=349 단면을 픽셀 순서대로 옮긴 그라디언트)·혜성·오브젝트 뒤 글로우·타일·노드·FAQ 빛 헤어라인에 "빛"으로만 쓴다. 장면 순서·타이밍(루프 4.2s·교체 267+333ms·점등 0.9~1.3s·조립 1.3s)을 RA §4 수치 그대로 옮겼고, 트립틱은 브리프 확정대로 **가로**이면서 레퍼런스 서명인 "가운데 고정 오브젝트 교체"를 살렸다. 감점 4: 히어로 한 화면에 혜성·펄스·말풍선 셋이 함께 움직여 v1 이 들은 "지저분" 쪽으로 기울 여지, 기능 행 R2 가 렌더 3개 + 선 3토막으로 붐빈다.
- **memorable 10**: 혜성 끝에서 앱 말풍선이 피는 순간은 좋지만 레퍼런스 원형과 너무 가깝다. 스스로 R1 "Sellix 복제" 위험을 1순위로 적었다.
- **facts 17**: 인용 정확, 신규 크롭은 모두 원본 크롭·리사이즈, 숫자 격자 8칸에 출처, 위젯 수·'일곱' 제외. 감점: 트립틱 2번 `poke-panel` 이 센터 배지 4개를 1.4배로 보여 준다(표본 19), R4 `league-panel` 도 배지가 보인다, sr-only 절 제목 "하루의 세 장면"은 CB 에 없는 신규 문구.
- **perf 13**: 첫 화면 308KB·전체 1.68MB, 합산이 정확하다. 루프 상한, 감속 모션 판 전부 정의, 트립틱 장마다 `tabindex` + 포커스 시 머묾 위치로 스크롤, 390 세로판이 감속 판과 같은 DOM. 감점: sticky 조상 규칙 없음, `.dome::before` 의 `mix-blend-mode: screen` 이 패럴랙스로 움직이는 1260px 층 위에서 합성 비용을 키운다, 짧은 화면(789) 히어로 배치 미검증.
- **rhythm 9**: 10.9 뷰포트(상한 안), 가운데 → 고정 → 가운데 → 왼쪽 행 → 왼쪽 제목 격자 → 가운데+두 열 → 왼쪽 제목 FAQ → 가운데. 같은 구도가 연달아 두 번 넘지 않는다. 행 5개도 타일 유무·자식 수로 변주.

1. 트립틱 2번 오브젝트를 배지 없는 크롭으로 교체(예: 아바타 열을 뺀 `poke_list` 크롭, 또는 `poke_row_mint` 한 줄 + 말풍선). R4 리그 패널도 배지가 작게 보이는 크기로 줄이거나 아바타 열 제외 크롭.

## 4. 후보 B — 78점

### 4.1 근거
- **fit 32**: 체험 0, 바탕·빛을 앱 아이콘 링에서 표본해 "다크+보라"의 근거가 가장 제품적이다. 감점: 트립틱을 **세로**로 정했다 — 레퍼런스 실측(RA §0.2-2)에는 맞지만 브리프 §5.1 "확정" 항목(가로 스크럽)과 어긋난다(가로판은 부록). 아잉이 8자리(히어로·트립틱 3·행 스틸 3·아웃트로)에 나와 행마다 렌더 + 아잉 스틸 + 말풍선 + 선 + 타일이 겹친다 — 사용자가 v1 에서 싫어한 "여럿이 움직이는/붙어 있는 화면"에 가깝다.
- **memorable 13**: 레퍼런스의 지구 자리에 진짜 3D 아잉이 서는 보라 돔, 처음과 끝 같은 자리 — 레퍼런스 복제가 아니라 이 제품만의 것.
- **facts 16**: 인용 정확, 앱 반응·말풍선 짝을 꼼꼼히 맞췄다(milestone 엔 말풍선 없음, 메시지 수신 = poked). 감점: 잔디 `steps(12)` ↔ 실제 13열(표본 14), 행 ①(`popover-on`, 10:20)과 행 ②(`popover-working`, 14:05)가 540px 간격이라 900 화면 하나에 **같은 팝오버가 다른 팀 숫자로 둘** 보인다(v1 §1.3-8 취지 위반), 퇴근 꾸벅 → idle 은 앱에 없는 상태(브리프가 허용한 선택지라 감점 작게), `token-month` 배지.
- **perf 10**: 바이트는 정직하지만 3.13MB 이고, idle 한 번 계상은 브라우저 캐시 가정에 걸려 최악이면 예산을 넘는다. 히어로·아웃트로 idle 무한 루프(2.2.2). 무대 다섯 + `stage-bus` + 프레임 시크 이음은 셋 중 구현 위험이 가장 크다(웹킷 HEVC 알파 시크 오차). 장점: 로드 전 영상 0건, 2.5초 도착 마감, CSS scroll-driven 패럴랙스(JS 0), 1440×789 실측, rest 포스터 픽셀 동일 검증.
- **rhythm 7**: 10.7 뷰포트는 좋으나 설치(가운데 H2)·FAQ(가운데 한 칼럼)·아웃트로(가운데) 세 절이 연달아 가운데다. 기능 행 6개는 "문법은 하나"를 금지 조항으로 박아 변주가 없다.

### 4.2 mustFix (B 가 뼈대가 될 경우)
1. idle 루프 상한(예: 2회 뒤 rest 포스터) — 히어로·아웃트로.
