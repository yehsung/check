# 알까기만 실행하기

macOS 14 이상, Swift 6 이상에서 저장소 루트 기준으로 실행한다.

```sh
./scripts/alkkagi.sh run
```

로그인 없는 한 창 연습 모드가 열린다. 온라인의 동시 비공개 배치는 아래에 연결된 두 계정 실행기로 검증한다.
한 창 연습에서는 흑돌과 백돌이 순서대로 각자 30초 안에 자기 영역에 돌 5개를 배치한다.
돌을 고르고 판을 눌러 놓거나 이미 놓은 돌을 잡아 옮길 수 있다. 5개를 놓으면 [배치 완료]를 누를 수 있으며,
시간이 끝나면 남은 돌은 자동 배치한다. 흑돌부터 번갈아 플레이한다.

내 돌을 잡고 뒤로 당겼다가 놓으면 반대 방향으로 발사된다. 앞쪽 궤적 화살표는 표시하지 않는다.
한 수는 30초이며 시간 초과 시 차례를 넘긴다. 발사 후에는 시계를 멈추고 돌이 모두 멈춘 뒤 차례가 바뀐다.
돌의 중심이 판 밖으로 나가면 탈락하며 상대 돌을 모두 떨어뜨리면 승리한다.
탈락한 돌은 판 경계를 넘어 아래 층으로 낙하한다. 한 번의 발사로 양쪽 돌이 모두 떨어지면 무승부다.
`Esc`는 조준 취소, `⌘R`은 새 판이다. 채팅 중 일반 `R` 입력은 새 판을 시작하지 않는다.

오목과 같은 바둑판, 흑백 돌, 시계 링, 말풍선을 공유하며 채팅은 기존 한글 조합 처리 입력기를 사용한다.
창 크기와 두 열 구성도 오목과 같다. 왼쪽에는 판만, 오른쪽에는 닉네임과 시계가 있는 두 사람 카드,
배치 또는 차례 상태, 채팅을 둔다. 로그인 없는 전용 실행기는 플레이어 1과 플레이어 2로 표시한다.
Enter 또는 ⌘Enter로 보내고 Shift+Enter로 줄을 바꾼다. 기본 실행기의 대화는 같은 창에서만 주고받는 로컬 대화다.
본앱에서는 미니게임의 [같이 하기] 목록 맨 아래 [알까기]에서 온라인 로비를 연다.

## 알까기 테스트만 실행하기

```sh
./scripts/alkkagi.sh test
./scripts/alkkagi.sh test --filter Alkkagi
```

이 독립 Swift 패키지는 알까기와 공유 화면 부품만 빌드한다. 루트 패키지의 다른 게임과
메뉴바 앱, 기존 전체 테스트는 빌드하지 않는다. 로그인, JWT, 키체인, Supabase 연결도 필요 없다.

`Sources/AlkkagiCore/AlkkagiGame.swift`와 실행기 아래의 `AlkkagiGameView.swift`는
저장소의 실제 게임 소스를 가리키는 심볼릭 링크다. 테스트용 엔진 사본을 따로 두지 않는다.
입력 제스처 테스트도 본앱과 같은 파일을 링크해, 시간 초과와 취소한 드래그의 재사용을 함께 검증한다.

공용 화면 구성은 `Sources/check/BoardGameComponents.swift`에 있다. `BoardGameDrawing`은 판과 돌을,
`BoardGameMatchLayout`과 `BoardGameMatchSidebar`는 두 열과 오른쪽 순서를,
`BoardGamePlayerCard`와 `BoardGameChatCard`는 닉네임과 시계 및 채팅의 공통 틀을 담당한다.
오목과 알까기는 이 부품을 실제로 함께 사용하고, 게임별 규칙과 입력 처리만 각 화면에서 공급한다.

Finder에서 열 수 있는 로컬 앱 번들이 필요하면 다음 명령으로 만든다.

```sh
./scripts/alkkagi.sh app
```

생성 위치는 `playgrounds/alkkagi/.build/Alkkagi Playground.app`이다.
실제 HTTP API를 사용하는 두 계정 실행기와 서버 반영 절차는
[온라인 대전 문서](../../docs/plan/alkkagi/README.md)에 있다.
기본 한 창 모드는 로그인과 서버 없이 동작하며 미션 지급은 연결하지 않는다.
온라인은 같은 30초 동안 동시에 비공개로 배치하고, 서버가 확정한 경기 종료 후 기존 미션 상태를 조회한다.
